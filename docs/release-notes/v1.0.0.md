# THE VOID DOWNLOADER 1.0.0

**The first stable release.** Download video and audio from YouTube and 1,000+ other sites, on **Linux, Windows and Android**. A THE VOID project by THE VOID PROTOCOL.

## ✨ Highlights

- 🎬 **Video up to 4K**, or 🎵 **audio only** as MP3, M4A or Opus
- 📃 **Whole playlists**, saved into their own folder with numbered files
- ⏬ **A download queue** with progress, speed, time left, cancel and retry
- 🏷️ **Ready-to-play files**: title, artist, cover art, chapters and subtitles saved inside the file
- 📱 **Android: Share → THE VOID DOWNLOADER** from the YouTube app. Downloads continue in the background
- 🔐 **Signed-in downloads**: uses your browser's login for age-restricted or members-only videos
- 📦 **Everything included**: the AppImage, Windows and Android builds bundle yt-dlp and ffmpeg, so there's nothing else to install
- 🔒 **Private**: no account, ads, tracking or analytics

Your downloads are saved to a **`THE VOID DOWNLOADER`** folder: `~/Downloads/THE VOID DOWNLOADER/` on Linux and Windows, and `Download/THE VOID DOWNLOADER/` on Android.

## ⬇️ Which file do I need?

| Device | Download |

| **Linux (any distro)** | `THE-VOID-DOWNLOADER-1.0.0-x86_64.AppImage`, then `chmod +x` it and run |
| **Arch / Manjaro / CachyOS** | `yay -S yt-downloader` |
| **Windows 10/11** | `THE-VOID-DOWNLOADER-1.0.0-Setup.exe` (installer) or `…-Windows-Portable.zip` |

Full install instructions are in the [README](https://github.com/MRVIMA/yt-downloader#installation).

## ⚠️ Good to know

- **Windows:** SmartScreen may warn about an "unrecognized app", because the installer isn't code-signed yet. Click **More info → Run anyway**.
- **Android:** if you installed a test build, uninstall it first. Google Play doesn't allow YouTube downloaders, so updates come from here (GitHub Releases).
- **AppImage:** if it won't start, run it with `--appimage-extract-and-run`, or install `libfuse2`.
- **If downloads stop working:** sites change often. Update yt-dlp (Android: ⚙ Settings → Update yt-dlp) or install the latest release.
